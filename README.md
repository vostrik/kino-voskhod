# Кинотеатр «Восход»

Учебный макет сайта кинотеатра: расписание сеансов на неделю вперёд, три зала,
демо-покупка билета.

## Как открыть

- Онлайн: https://vostrik.github.io/kino-voskhod/
- Локально: открыть `index.html` в браузере или выполнить
  `python3 -m http.server` в папке проекта.

## Структура

| Файл | Что внутри |
|---|---|
| `index.html` | разметка страницы |
| `styles.css` | стили |
| `data.js` | фильмы, залы, генератор сеансов на 7 дней |
| `app.js` | отрисовка расписания, фильтры, модальное окно |
| `MENTI.md` | подсказки: как искать проблемы, инструменты, формат отчёта |

Данные вымышлены. Изображения — заглушки с [picsum.photos](https://picsum.photos).
