# Кинотеатр «Восход»

Учебный макет сайта кинотеатра: расписание сеансов на неделю вперёд, три зала,
демо-покупка билета. Оптимизирован до 100/100 в Lighthouse
(производительность и доступность).

## Как открыть

- Онлайн: https://vostrik.github.io/kino-voskhod/
- Локально с правильными заголовками кеша и gzip:
  `python dev-server.py` → http://localhost:8000 и https://localhost:8443
  (HTTPS нужен, чтобы локальный антивирус не внедрял свой скрипт в страницы
  и не портил замеры Lighthouse)
- Совсем просто: открыть `index.html` в браузере.

## Структура

| Файл | Что внутри |
|---|---|
| `index.html` | разметка + все стили инлайном (единый запрос — мгновенная отрисовка, CLS = 0) и @font-face |
| `app.js` | отрисовка расписания, фильтры, модальное окно (Esc, ловушка фокуса), сообщения без alert |
| `data.js` | фильмы, залы, генератор сеансов на 7 дней |
| `fonts/` | самохостинговые шрифты (Roboto 400 и Playfair 700, сжаты под алфавит сайта, font-display: optional) |
| `img/` | постеры и баннер: `.avif` (hero, самый лёгкий), `.webp` (сжаты, 2× ретина) + `.jpg` как запасной вариант |
| `styles.css` | заметка: стили переехали инлайном в index.html |
| `dev-server.py` | локальный сервер: Cache-Control 1 год, gzip, HTTPS |
| `MENTI.md` | подсказки: как искать проблемы, инструменты, формат отчёта |

Данные вымышлены. Изображения — фото-заглушки, лежат в `img/` и отдаются
с того же домена, что и сайт.
